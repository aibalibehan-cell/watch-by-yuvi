## Overview
A bespoke high-precision automatic tourbillon timepiece showcase rendered with real-time WebGL, Three.js, and standalone 3D GLTF models.

## Standalone 3D Models (`models/`)
- `watch.glb` — Master 3D Watch Assembly
- `tourbillon.glb` — Tourbillon Mechanism
- `mainplate.glb` — Mainplate Assembly
- `dial.glb` — Dial & Complications
- `barrel.glb` — Mainspring Barrel
- `backplate.glb` — Exhibition Caseback
- `weight.glb` — Automatic Rotor Weight
- `bracelet.glb` — Steel Link Bracelet & Clasp

## Getting Started
```bash
node server.js
```
Open `http://localhost:3000` in your browser.
